How to add a Critical Data Element

A Critical Data Element (CDE) identifies a single source field that the organisation has committed to monitoring for data quality. Each CDE must belong to a Critical Data Set.

A Critical Data Set must exist before you can add a CDE. If no CDS exists yet, add a CDS first.

Opening the form

There are three ways to open the Add CDE form. Each pre-fills some fields to save time:

  • + CDE in the page header — opens a blank form. You select the CDS manually using cascading agency and directorate dropdowns.
  • + CDE on a CDS row — pre-fills the Critical Data Set. The CDS field is fixed to that data set.
  • + CDE on a Table row — pre-fills the CDS, database name, table name, platform, system, and snapshot filter from existing CDEs in that table.

Steps

  1. 1
    Click the + CDE button using whichever entry point suits your context (see above).
  2. 2
    If you used the header button, select the Critical Data Set using the cascading dropdowns: first choose the agency, then the directorate, then the data set.
    If a directorate or data set does not appear, it may not yet exist. Add it first before returning here.
  3. 3
    Select the source table. If the table has been added to the Table Library, choose it from the Select from Table Library dropdown. This automatically fills the database and table name and offers a field picker from the known columns.
    If the table is not in the Table Library, choose Enter manually from the dropdown and type the database name, table name, and field name directly.
  4. 4
    Select or type the Source Field. If you selected from the Table Library, a dropdown lists the known columns.
  5. 5
    Enter the Snapshot Filter. This is required and is used to construct the SQL queries run against this field.
    Use the same SQL WHERE clause fragment that isolates the relevant snapshot of this table, for example snapshot_date = '{snapshot}'.
  6. 6
    Optionally add a Definition and Explanation describing the business meaning of this field.
  7. 7
    Optionally set Criticality ratings. Each criticality group (if any are configured) shows a dropdown to assign a level to this CDE. You can leave these blank and update them later.
  8. 8
    Click Add. The CDE appears immediately under its table in the hierarchy.

Required fields

FieldNotes
Critical Data Set requiredThe data set this CDE belongs to. Fixed after saving.
Database Name requiredThe source database where this field lives.
Table Name requiredThe source table containing this field.
Field Name requiredThe exact column name in the source table.
Snapshot Filter requiredA SQL filter fragment used when composing data quality queries. Missing this causes a warning indicator on the CDE and prevents SQL from being generated.
Platform optionalSource platform name (e.g. AWS, Azure).
System optionalSource system name (e.g. the application that owns the data).
Definition optionalBusiness definition of the field.
Explanation optionalAdditional context about the field or its usage.
A CDE with a missing snapshot filter shows a red warning indicator in the hierarchy. Rules assigned to that CDE will also show a warning and the SQL viewer will be disabled until the filter is added. Edit the CDE to fix this.
