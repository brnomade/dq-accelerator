How to edit or retire a Critical Data Element

You can update any field on an existing CDE, retire it to remove it from active monitoring, or restore a previously retired CDE.

Edit a CDE

  1. 1
    Expand the Agency, CDS, and Table rows until the CDE row is visible.
  2. 2
    Click the pencil icon on the right side of the CDE row. The Edit CDE panel slides open.
  3. 3
    Update any field you need to change.
    The Critical Data Set is shown as read-only in edit mode and cannot be changed. To move a CDE to a different data set, retire it and create a new one.
  4. 4
    Click Save. The changes take effect immediately in the hierarchy.
If the CDE has a missing snapshot filter, a red warning icon appears on the row. Edit the CDE and add the snapshot filter to clear the warning. Without it, data quality SQL cannot be generated for any rules assigned to this CDE.

Retire a CDE

Retiring marks a CDE as inactive. It is not deleted and can be restored if needed.

  1. 1
    Expand the hierarchy until the CDE row is visible.
  2. 2
    Click the eye-off icon (strikethrough eye) on the right side of the CDE row. The CDE is retired immediately — there is no confirmation prompt.
  3. 3
    The CDE disappears from the active view. If the Show retired toggle is enabled, it reappears in a faded state with a retired label.

Restore a retired CDE

  1. 1
    Enable the Show retired toggle in the toolbar. This toggle appears only when retired CDEs exist.
  2. 2
    Expand the hierarchy to locate the retired CDE (shown faded with a retired label).
  3. 3
    Click the eye icon on the right side of the retired CDE row. The CDE is restored immediately and returns to active status.
