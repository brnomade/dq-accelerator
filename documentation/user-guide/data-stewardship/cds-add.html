How to add a Critical Data Set

A Critical Data Set (CDS) is a named group of related data fields under a single directorate. CDEs can only be assigned to an existing CDS, so create the CDS first before adding CDEs to it.

  1. 1
    Click Data and Stewardship in the left sidebar.
    If your steward identity is not yet set, you can view records but not make changes. See How to set your steward identity.
  2. 2
    Click the + CDS button in the top-right of the page header.
    Alternatively, expand an Agency row and click the + CDS button on the right of that agency's header row. Using the per-agency button pre-fills the agency if that agency has only one directorate.
  3. 3
    Fill in the form panel that slides open. Required fields are marked with a red asterisk.
    See the field reference below.
  4. 4
    Click Add to save. The new CDS appears immediately under its agency in the hierarchy.

Field reference

FieldNotes
Data Set Name required A short descriptive name for the data set. This name appears throughout the hierarchy and in exports.
Directorate required The directorate that owns this data set. Select from the dropdown. The owning agency is derived automatically from the directorate you choose.
Description optional A brief explanation of what the data set covers. Displayed under the CDS name in the hierarchy view.
Subdivision optional A secondary grouping or sub-division label within the data set, if applicable.
A CDS must belong to a directorate. If no directorates exist yet, add them first under Ownership Hierarchy in the sidebar before creating a CDS.
