How to navigate the Data and Stewardship page

The Data and Stewardship page organises all Critical Data Elements (CDEs) in a collapsible four-level hierarchy. Understanding the layout helps you find, add, and manage records efficiently.

The four levels

Every CDE sits inside a table, which belongs to a Critical Data Set (CDS), which belongs to an Executive Agency. The page displays these four levels as nested expandable rows.

LevelWhat it shows
Executive AgencyThe top-level organisational owner. Displays the agency acronym and name. Summary counts show the number of CDSs, tables, fields, CDEs, rules, and metrics beneath it.
Critical Data SetA named group of related data fields owned by the agency. Summary counts show tables, fields, CDEs, rules, and metrics within the set.
TableA source database table. Shows the table and database name, a profiled / not profiled badge, and field, CDE, rule, and metric counts.
CDE (field)An individual source field tracked as a Critical Data Element. Shows the field name, any criticality ratings, profiling badge, and rule and metric counts.

Expanding and collapsing rows

Click any Agency, CDS, or Table row to expand or collapse it. Only expanded rows reveal the level below. All levels start collapsed when you open the page.

To expand a CDE row and see its rule allocations, click the chevron button that appears on the right side of the CDE row when it has at least one rule assigned.

Searching

Type in the search box at the top of the page to filter by agency acronym or name, data set name, table name, field name, or database name. The hierarchy collapses to show only matching entries. Clear the search to restore the full view.

Toolbar options

My data — visible only when your steward identity is set and you have CDS assignments. Scopes the view to data sets assigned to you. See How to scope the view to your data sets.

Show retired — a toggle that appears when retired CDEs exist. Enable it to show retired records alongside live ones. Retired records appear faded.

The summary counts at each level update immediately when you add or retire a record. If a level appears empty, it means no records exist yet at that level, or the search filter has hidden them.
