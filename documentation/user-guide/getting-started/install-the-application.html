How to install the application

The application is a single HTML file. There is nothing to install in the traditional sense — you locate the file and create a browser bookmark. This guide covers two approaches. Use the recommended approach wherever possible.

Recommended approach

Use the shared OneDrive location

The Steward Master publishes every new build to a fixed, shared OneDrive folder. When you sync that folder and bookmark the file from it, your bookmark always points to the latest version — no manual updates needed. This is the preferred approach for all users.

Step 1 — Sync the shared folder

  1. 1
    Contact your Steward Master and ask for access to the shared OneDrive application folder if you have not already received an invitation.
    The Steward Master controls the shared location where all builds are published.
  2. 2
    Open the shared folder link in your browser. In the OneDrive toolbar, click Sync.
    This adds the folder to your local OneDrive sync and makes it visible in Windows Explorer.
  3. 3
    Wait for the sync to complete. Open Windows Explorer and navigate to the synced folder, which will appear under OneDrive — [Your Organisation] in the left panel.
  4. 4
    Confirm you can see dq-accelerator.html inside the folder.
    If you also see a documentation/ subfolder alongside it, the folder structure is correct.

Step 2 — Create a browser bookmark

  1. 5
    Double-click dq-accelerator.html to open it in your default browser, or drag the file into an open browser window.
  2. 6
    Once the application loads, bookmark the page in your browser.
    In Chrome or Edge: press Ctrl + D. Name the bookmark something clear, such as DQ Accelerator.
  3. 7
    Close the tab. From now on, open the application using this bookmark.
    Each time the Steward Master publishes a new build, the file in the shared folder is overwritten. Your bookmark points to that same file path, so you will always open the latest version automatically — no action required on your part.
Alternative approach

Copy the build to your local drive

Use this approach only if you cannot sync the shared OneDrive folder — for example, if you are working offline or do not have OneDrive access. With this approach you must repeat the process each time a new build is released.

Step 1 — Obtain and extract the build

  1. 1
    Receive the ZIP file from your Steward Master (via email or shared link). The filename contains the build number, for example dq-accelerator-build-20260701-1430.zip.
  2. 2
    Choose a permanent location on your local drive to keep the application, for example Documents\DQ Accelerator\. Create the folder if it does not exist.
    Choose a location you will remember and keep consistent across upgrades.
  3. 3
    Extract the ZIP into that folder. Do not open the HTML file from inside the ZIP — it must be extracted first so the documentation/ subfolder is present alongside it.
  4. 4
    Confirm you can see dq-accelerator.html and the documentation/ folder in your chosen location.

Step 2 — Create a browser bookmark

  1. 5
    Double-click dq-accelerator.html to open it in your browser, or drag the file into an open browser window.
  2. 6
    Bookmark the page. Press Ctrl + D in Chrome or Edge. Name it DQ Accelerator.

Upgrading when a new build is released

  1. 7
    When your Steward Master distributes a new build, extract the new ZIP into the same folder, overwriting the existing files.
  2. 8
    Your existing bookmark will continue to work because the filename does not change between builds.
    If you extract to a different folder, your existing bookmark will still open the old version. Always extract to the same location, or update the bookmark to point to the new file.
