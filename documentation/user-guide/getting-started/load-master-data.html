How to load the master data

The master data file (dq_master_*.json) is distributed by your master steward. Load the latest version at the start of every session after resetting. If you have more than one file, always use the one with the highest version number in its name.

Export any pending changes and reset your data before loading. Loading master data over existing changes will trigger a warning. See How to export your changes and reset.
  1. 1
    Click Import in the left sidebar, under Database Actions. If you have just reset, the application opens here automatically.
  2. 2
    Drag the master data file (dq_master_*.json) onto the drop zone, or click the zone to browse for the file. If you have multiple files, pick the one with the highest version number.
    The filename encodes the date and a daily sequence: dq_master_master-YYYYMMDD-NNN.json. A later date or higher sequence number means a newer file. See How to import the master data file for a full explanation with examples.
  3. 3
    If a warning appears about uncommitted changes, stop here. Export your delta first, then reset, then come back and repeat from step 1.
    See How to export your changes and reset.
  4. 4
    The data loads and the application moves to the Dashboard. The record counts in the header confirm the data is in place.
  5. 5
    Set your steward identity before making any changes.
    See How to set your steward identity.
The master data file is not an Excel file. If you have only an Excel spreadsheet, contact your master steward to obtain the correct .json master file.
