How to open the application

The application runs as a local HTML file. It does not connect to the internet or save data automatically between sessions. You must reload master data at the start of every session.

Step 1 — Check you have the latest build

  1. 1
    If the application is already open, look at the build number shown below the application name in the top-left of the header. It reads build-YYYYMMDD-HHMM.
  2. 2
    Compare it against the filename of the latest zip file you have received from your master steward. The zip filename contains the same build number.
    If your open build is older, close the application and use the latest zip.

Step 2 — Extract and open

  1. 3
    Extract the zip file to a folder on your computer. Do not open the HTML file from inside the zip — it must be extracted first so the user-guide/ folder is present alongside it.
  2. 4
    Open dq-accelerator.html in your browser by double-clicking it or dragging it into a browser window.
  3. 5
    The application opens on the Import screen. This is normal — no data is loaded yet.

Session best practice — follow this order every time

1
If you have unsaved changes from a previous session still in the browser, export your delta first before doing anything else.
2
Reset your data to clear the previous session from the browser.
3
Load the latest master data file from your master steward.
4
Do your work. When done, export your delta and reset before closing.
Data stored in the browser is not permanent. Clearing browser history, cookies, or site data will erase it. Always export before closing your session.
