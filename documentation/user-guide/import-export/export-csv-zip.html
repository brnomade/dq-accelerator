How to export a full backup

The backup export downloads all data quality tables as individual CSV files bundled into a single ZIP archive. It captures the complete current state of your local data store and is available to all users.

For Athena upload, use the master copy only. When uploading to Athena, make sure you are exporting from a fully merged master file, not a working steward copy with unmerged changes. Stewards should use this export only for their own local backup.
  1. 1
    Click Export in the left sidebar.
  2. 2
    Find the Backup export card.
  3. 3
    Check the Include soft-deleted records toggle. Leave it off (live only) for a standard export. Turn it on only if you need the full audit trail including retired records.
    Default: live records only.
  4. 4
    The card shows the total number of CSV files and record counts that will be included. Verify these look correct before proceeding.
  5. 5
    Click Export backup. A file named dq_export_YYYYMMDD_HHMMSS.zip downloads to your computer.
  6. 6
    To upload to Athena, extract the ZIP and upload each CSV to the corresponding Athena table by filename (for example, data_quality_rule.csv loads into the data_quality_rule table).
The master steward also has access to per-group and per-table CSV exports below the Backup export card. These allow downloading a single table or a logical group (for example, all stewardship tables). These options are not shown to regular stewards.
