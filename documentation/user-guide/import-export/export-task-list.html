How to export a Task List

The Task List export generates a CSV file of data quality rule allocations scoped to your data. Each row represents one allocation and contains all the information needed to create a Trello implementation card. Rows are labelled either IMPLEMENT (no SQL written yet) or TEST (SQL exists and is ready to verify).

Your steward identity must be set before exporting. The export is automatically scoped to the CDEs in your assigned Critical Data Sets. Go to Settings (top-right cog icon) and select your name under Steward Identity.

Master stewards see all allocations across the organisation.
  1. 1
    Click Export in the left sidebar, under Database Actions.
  2. 2
    Click the Task List tab at the top of the Export page. The tab is available to all recognised users.
  3. 3
    Review the preview table. Each row shows one rule allocation with its agency, CDS, CDE details, rule name, quality dimension, and assigned stewards. Rows labelled IMPLEMENT have no SQL defined yet. Rows labelled TEST include the fully substituted SQL code ready to verify against the target CDE.
  4. 4
    To inspect the full content of a row, including the complete SQL code, click anywhere on the row. A panel slides in from the right showing all fields. Click the backdrop or the X button to close it.
  5. 5
    To view the full value of any truncated cell without opening the panel, hover the mouse over the cell. A tooltip shows the complete text.
  6. 6
    All rows are pre-selected by default. To exclude a row from the export, uncheck its checkbox. To deselect all rows at once, uncheck the header checkbox. To reselect all, check it again.
  7. 7
    Click Export N selected rows. A file save dialog opens. Choose where to save the file. The filename follows the pattern dq_task_list_[name]_[timestamp].csv.
The exported CSV contains 13 columns: Task Type, Agency Acronym, CDS Name, CDE Table, CDE Database, CDE Field, Quality Dimension, Rule Name, Rule Explanation, Steward Name, SQL Code, SQL Sample, and SQL Snapshot Filter. SQL columns are populated only for TEST rows. When multiple stewards are assigned to a CDS, their names appear in the Steward Name column separated by a hyphen.
