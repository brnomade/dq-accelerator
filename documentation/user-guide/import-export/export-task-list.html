How to export a Task List

The Task List export generates a CSV file of data quality rule allocations scoped to your data. Each row represents one allocation and contains all the information needed to create a Trello implementation card. Rows are classified as IMPLEMENT (no SQL written yet) or TEST (SQL is defined and ready to verify against the target CDE).

Your steward identity must be set before exporting. The export is automatically scoped to the CDEs in your assigned Critical Data Sets. Go to Settings (top-right cog icon) and select your name under Steward Identity.

Master stewards see all allocations across the organisation.

Opening the Task List tab

  1. 1
    Click Export in the left sidebar under Database Actions.
  2. 2
    Click the Task List tab at the top of the Export page. The tab is available to all recognised users — both stewards and master stewards.

Reviewing the preview table

  1. 3
    The preview table shows all allocations in scope, grouped first by Agency and then by CDS within each agency. Each group header shows the group name and a row count.
    Rows labelled IMPLEMENT have no SQL defined yet — a developer needs to write it. Rows labelled TEST include the fully substituted, ready-to-run SQL code for that specific CDE.
  2. 4
    To collapse or expand an Agency or CDS group, click the triangle symbol to the left of the group name. Collapsing a group hides its data rows but keeps the group header visible. Collapsed rows are still included in the export if their checkboxes are selected.
  3. 5
    To sort rows by a column, click that column’s header. Click again to reverse the sort direction. An arrow indicator shows the active sort column and direction. Sorting applies within each group independently; group order (alphabetical by agency, then by CDS) is not affected.
  4. 6
    To inspect a row in full — including the complete Failures Counter and Denominator Counter — click anywhere on the data row. A panel slides in from the right showing all fields. Click the backdrop or the X button to close it.
  5. 7
    To view a truncated cell value without opening the panel, hover the mouse over the cell. A tooltip shows the complete text.

Selecting rows for export

  1. 8
    All rows are pre-selected by default. Use checkboxes to control what is included in the export:
    • Header checkbox (top-left of the table) — selects or deselects all rows at once.
    • Agency checkbox (on the agency group header row) — selects or deselects all rows in that agency.
    • CDS checkbox (on the CDS group header row) — selects or deselects all rows in that CDS.
    • Row checkbox — selects or deselects that individual row.
    A checkbox shows a dash (indeterminate) when only some rows in its group are selected.

Exporting the file

  1. 9
    Click Export N selected rows. The button shows the number of currently selected rows and is disabled when none are selected. A file save dialog opens — choose a location and confirm. The filename follows the pattern dq_task_list_[name]_[timestamp].csv.
The exported CSV contains 13 columns: Task Type, Agency Acronym, CDS Name, CDE Table, CDE Database, CDE Field, Quality Dimension, Rule Name, Rule Explanation, Steward Name, Failures Counter SQL, Denominator Counter SQL, and CDE Snapshot Filter SQL. SQL columns are populated only for TEST rows — they are empty for IMPLEMENT rows. When multiple stewards are assigned to a CDS their names appear in the Steward Name column separated by a hyphen. Collapsing a group in the preview does not affect what is exported — only the checkbox state determines inclusion.
