How to import the master data file

The master data file is distributed by your master steward at the start of each working period. Importing it loads the shared dataset into the application so you can begin editing.

Export any pending changes and reset your data before importing. If you load master data over unsaved changes, those changes will be lost. See How to export your delta and How to export your changes and reset.

Identifying the correct file

Master files follow a fixed naming convention that encodes the date and a daily sequence number. Always load the file with the highest version number.

File name format
dq_master_master-YYYYMMDD-NNN.json
YYYYMMDD — the date the file was produced (year, month, day).
NNN — a sequence number that increments each time a new master is exported on the same day, starting at 001.

Examples: if your master steward sends files over several days, the names will look like this.

Which file to pick
dq_master_master-20260628-001.json older date
dq_master_master-20260701-001.json earlier on same day
dq_master_master-20260701-002.json earlier on same day
dq_master_master-20260701-003.json ✓ use this one
How to read the version: Compare the date part first — a later date is always newer regardless of sequence. If the date is the same, the higher sequence number is newer. 20260701-003 is newer than 20260701-002, and both are newer than 20260628-001.

If in doubt, ask your master steward which file to use. Loading an older version will not cause an error, but your delta will be built against outdated data and may produce version-mismatch warnings when the master steward merges it.

Importing the file

  1. 1
    Click Import in the left sidebar. If you have just reset the application, it opens on the Import screen automatically.
  2. 2
    Drag the master data file onto the drop zone, or click the zone to browse for the file. Make sure you select the latest version as described above.
  3. 3
    If a warning appears about uncommitted changes, stop. Export your delta first, reset, then return to step 1.
    See How to export your delta.
  4. 4
    The data loads and the application moves to the Dashboard. The record counts in the header confirm what was loaded.
  5. 5
    Set your steward identity before making any changes.
    See How to set your steward identity.
The master data file is a .json file, not an Excel file. If you only have an Excel spreadsheet, contact your master steward to obtain the correct file.
