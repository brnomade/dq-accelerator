How to inspect raw table data

The Data Browser gives the master steward direct read access to all tables in the data store. It shows raw physical field names and values with no filtering or display formatting applied, making it useful for auditing records and investigating data integrity issues.

Master steward only. The Data Browser is not visible to regular stewards. You must have a master steward identity configured to access it.

Opening the Data Browser

  1. 1
    Click Data Browser in the left sidebar. It appears near the bottom of the navigation, below Import.
  2. 2
    The screen opens with the first table selected. The left panel lists all tables alphabetically by physical name.
    Hover over a table name to see the full name in a tooltip if it is too long to display.
  3. 3
    Each table row shows two numbers separated by a slash: active rows on the left, total rows (including retired) on the right. The total turns amber when retired rows exist.
  4. 4
    A warning icon next to a table name indicates a data integrity issue: duplicate primary key values, or foreign key values that do not resolve to a valid parent record. Hover the icon to see details.
  5. 5
    Click any table name to load its rows in the grid on the right.

Reading the data grid

  1. 1
    Columns are shown in schema order, with the primary key column first. Column headers display the physical field name.
    A gold PK badge marks the primary key column. A blue FK badge marks foreign key columns.
  2. 2
    Click any column header to sort the grid by that column. Click it again to reverse the order.
  3. 3
    Use the Filter rows box in the toolbar to search across all column values in the selected table.
  4. 4
    Tick Show retired to include soft-deleted records. Retired rows appear at reduced opacity with an amber tint.
  5. 5
    Cells that contain long values are truncated with an ellipsis. Hover any cell to see the full value in a tooltip.
  6. 6
    Rows highlighted in red contain a duplicate primary key or an unresolved foreign key value.

Viewing the full record for a row

  1. 1
    Click any row in the grid. A detail panel slides in from the right showing every field and its complete value with no truncation.
  2. 2
    The panel header shows the table name. If the record is retired, a gold RETIRED badge appears next to the table name.
  3. 3
    Each field is labelled with its physical column name. The primary key field carries a gold PK badge; foreign key fields carry a blue FK badge. Fields with no value show null in italics.
  4. 4
    Long text values wrap across multiple lines so the full content is always visible.
  5. 5
    Click a different row to switch the panel to that record without closing it.
  6. 6
    Click the same row again, click the X button in the panel header, or click the dimmed area behind the panel to close it.
The Data Browser is read-only except for the Undo button on retired rows. Clicking Undo on a retired row restores it. All other edits must be made through the dedicated screens for each record type.
