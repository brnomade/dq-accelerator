How to read the Organisation page

The Organisation page shows the full accountability hierarchy as a list of agency rows. Each row summarises the patron, ownership, stewardship, data scope, and profiling coverage for that agency at a glance. Click a row to expand it and see the breakdown by directorate.

The agency row

Each agency card has two lines.

  1. 1
    Line 1 — the agency acronym and full name. A retired badge appears here if the agency has been retired.
  2. 2
    Line 2 — the patron name followed by a summary stat line. The Patron label comes first, then the patron’s name (or none assigned if no patron is set), followed by counts for every key dimension of the agency.

Stat line explained

The values in the stat line are separated by dots and read left to right in order of hierarchy depth.

StatWhat it counts
N directorate(s)Number of active directorates within the agency.
N ownersTotal data owners assigned across all directorates. Each directorate has at most one owner, so this equals the number of directorates that have an owner assigned.
N stewardsUnique data stewards working under this agency, counted by individual regardless of how many Critical Data Sets they are assigned to.
N CDSTotal Critical Data Sets across all directorates.
N CDETotal active Critical Data Elements across all directorates.
N rulesTotal rule allocations across all CDEs.
ProfilingPercentage of CDEs that have a field profile recorded. Shows no CDEs defined when there are no CDEs, no CDEs profiled when CDEs exist but none are profiled, and a percentage otherwise. 100% is highlighted in green.

Expanding an agency

  1. 1
    Click anywhere on the agency row to expand it. The chevron on the left rotates to indicate the open state.
  2. 2
    The expanded view shows each directorate as a branch. Each directorate row shows two lines: the directorate name on the first line, and on the second line the Owner label with the owner’s name (or none assigned), followed by counts for stewards, CDS, CDE, rules, and profiling scoped to that directorate only.
  3. 3
    Click the row again to collapse the agency.

Expanding a directorate

  1. 1
    Within an expanded agency, click any directorate row to expand it. Each directorate has its own independent chevron that rotates to show the open state.
  2. 2
    The expanded directorate shows a read-only list of Critical Data Sets sorted alphabetically. Each CDS entry is prefixed by a CDS type badge and shows three lines of detail to its right: the CDS name in bold with its stat line (CDE count · rule count · profiling coverage) on the first line; the stewards assigned to that CDS on the second line, each as a role pill followed by the steward’s name; and the CDS description on the third line.
  3. 3
    If a CDS has no stewards assigned, none assigned is shown in place of the steward list. If a CDS has no CDEs defined, the profiling stat reads no CDEs profiled.
  4. 4
    The CDS list is read-only. To add, edit, or retire a Critical Data Set or its stewardship assignments, use the Data and Stewardship page.
  5. 5
    Click the directorate row again to collapse it. Multiple directorates can be open at the same time.
The stat line counts reflect only active (non-retired) records. Toggle Show retired at the top of the page to include retired agencies and directorates in the view.
