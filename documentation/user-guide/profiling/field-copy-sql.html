How to copy the generated SQL for a field

The application generates ready-to-run SQL queries for each field based on its data type. Copy each query, run it in Athena, and paste the results back. The SQL is regenerated each time the panel opens, so there is no need to save it separately.

  1. 1
    Click Profiling in the left sidebar, under Database Actions.
  2. 2
    Click the table row header to expand it, then click Profile or Re-profile on the field you want to work on.
  3. 3
    In the panel, scroll to Step 2 - Run profiling queries and paste results. Six query sections are listed.
  4. 4
    Click Copy SQL next to the query you want. The button briefly shows Copied! to confirm the SQL is on your clipboard.
  5. 5
    Open Athena, paste the SQL into the query editor, and run it.
  6. 6
    Copy the results from Athena and paste them into the text area directly below the Copy SQL button.
  7. 7
    Repeat steps 4 to 6 for each applicable query.
    If a query shows Not applicable for this type, the query does not apply to this field’s data type. Skip it.
  8. 8
    Click Save profile or Update profile when done.

The six queries and what they measure:

Column Profiling
Null counts, distinct values, min/max, and type-specific statistics. Required.
Frequency Analysis
The top 50 most common values and their percentage of total rows.
Pattern Analysis
Classifies string values by detected type (integer, decimal, date, alpha, etc.). String fields only.
Length Profile
Distribution of value lengths. String fields only.
Duplicate Analysis
Total values, unique values, and uniqueness percentage.
Outlier Analysis
For numeric fields: values more than three standard deviations from the mean. For string fields: low-frequency values that may represent errors or exceptions.
If the field has a snapshot filter set on its CDE, the generated SQL includes a WHERE clause limiting the query to the relevant snapshot. The filter is shown in Step 1 of the profiling panel.
