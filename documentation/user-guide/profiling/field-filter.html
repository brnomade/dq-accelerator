How to filter fields by profiling status

The status filter narrows the Profiling view to show only the tables and fields that match a specific state. Use it to focus your work during a profiling session.

  1. 1
    Click Profiling in the left sidebar, under Data Quality Elements.
  2. 2
    Find the Filter dropdown in the filter bar at the top of the page, to the right of the search box.
  3. 3
    Select the status you want to work on. The list below explains each option.
All
Shows every table and field in scope. This is the default view.
Tables Pending
Shows only tables that have not yet been added to the Table Library. These need a DDL profile before field profiling can begin.
Fields Pending
Shows only fields that have not yet been profiled. Tables without any pending fields are hidden.
Blind Rules
Shows only fields that have quality rules allocated but no field profile. These rules are running without profiling data — address these first to ensure rules have full context.
Profiled
Shows only fields that have a completed profile. Use this to review or update existing profiles.
The search box and the status filter work together. You can type a table or field name in the search box and select a status at the same time to narrow the view further. Set the filter back to All to return to the full view.
