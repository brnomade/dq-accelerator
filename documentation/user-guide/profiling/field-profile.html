How to profile a field

Field profiling runs a set of SQL queries in Athena to characterise a field's content. The results are stored against the field so that data quality rules can be run with full context.

The table the field belongs to must already be in the Table Library before you can profile its fields. If the table shows an amber border, add it first. See How to add a table to the Table Library.

Step 1 — Open the field

  1. 1
    Click Profiling in the left sidebar, under Data Quality Elements.
  2. 2
    Click the table row header to expand it. A list of fields appears below.
  3. 3
    Find the field you want to profile. Fields not yet profiled show no green tick and a Profile button on the right.
    Fields with rules but no profile are highlighted in amber — these are the most important to address first.
  4. 4
    Click Profile. The field profiling panel opens showing the field name and its table.

Step 2 — Define the semantic type (optional)

  1. 5
    The Physical type is shown from the DDL. If the field's true data type differs (for example, a date stored as a string), select the correct type from the Override dropdown. This changes which SQL queries are generated.
    Leave the override blank to use the physical type as-is.

Step 3 — Run the profiling queries

  1. 6
    For each query in Step 2 - Run profiling queries and paste results, click Copy SQL next to the query name.
  2. 7
    Paste the SQL into Athena and run it.
  3. 8
    Copy the results from Athena and paste them into the text area below the Copy SQL button.
  4. 9
    Repeat for each applicable query. Queries that show Not applicable for this type are greyed out — skip those.
    The six queries are: Column Profiling (required), Frequency Analysis, Pattern Analysis, Length Profile, Duplicate Analysis, Outlier Analysis.

Step 4 — Add notes and save

  1. 10
    In Step 3 - Notes, add any relevant context: known data issues, business meaning, unusual patterns found. This is optional but useful for future reviews.
  2. 11
    Click Save profile. The field row shows a green tick to confirm the profile has been saved.
You do not need to complete all six queries before saving. Save with whatever results you have and update the profile later.
