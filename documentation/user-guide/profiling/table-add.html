How to add a table to the Table Library

Adding a table to the Table Library registers its column structure. This allows the application to generate the correct SQL queries when you profile individual fields.

Your steward identity must be set before making changes. Go to Settings (top-right cog icon) and select your name under Steward Identity.

Step 1 — Open the Table Library

  1. 1
    Click Profiling in the left sidebar, under Data Quality Elements.
  2. 2
    Find the table you want to add. Tables not yet in the library show an amber left border and have no profiled badge.
  3. 3
    Click Profile on the right side of the table row. The Table Profiling panel opens.

Step 2 — Identify the table

  1. 4
    In the Select from CDE related tables yet to be profiled dropdown, choose your table. The Database and Table fields fill in automatically.
    If the table is not in the dropdown, choose -- enter new database / table manually -- and type the database name and table name.

Step 3 — Get the DDL from Athena

  1. 5
    Once the database and table fields are filled, an Athena command appears: SHOW CREATE TABLE <database>.<table>;
  2. 6
    Click Copy to copy the command.
  3. 7
    Run the command in Athena and copy the full CREATE TABLE output it returns.
  4. 8
    Paste the output into the CREATE TABLE statement text area.
  5. 9
    Click Parse. The application extracts the column list from the DDL.

Step 4 — Verify columns and save

  1. 10
    Check the column list that appears in Step 2 - Verify columns. Columns that match CDEs are marked CDE. Columns already profiled are ticked.
  2. 11
    Click Add in the panel header. The table is added to the library and its row border changes to purple.
If Parse finds no columns, check that the pasted output is the full CREATE TABLE statement from Athena, not just the table name or a summary view.
