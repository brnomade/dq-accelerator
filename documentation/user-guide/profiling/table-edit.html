How to edit a table profile

Edit a table profile to update its column structure after a schema change, or to correct a DDL that was pasted incorrectly.

Your steward identity must be set before making changes. Go to Settings (top-right cog icon) and select your name under Steward Identity.
  1. 1
    Click Profiling in the left sidebar, under Data Quality Elements.
  2. 2
    Find the table. Profiled tables show a purple left border and a profiled badge.
  3. 3
    Click Re-profile on the right side of the table row. The Table Profiling panel opens showing the existing DDL and the date it was last profiled.
  4. 4
    Update the CREATE TABLE statement text area with the new DDL from Athena. Use the Copy button next to the Athena command to get the SHOW CREATE TABLE command, run it in Athena, then paste the output.
  5. 5
    Click Parse. The column list updates to reflect the new DDL.
  6. 6
    Check the Verify columns list to confirm the detected columns look correct.
  7. 7
    Click Save. The table profile is updated with the new column structure.
Editing a table profile does not change any field profiles already saved for that table. Field profiles are independent records and remain in place.
