How to generate rule suggestions for a field

The Rule Generator uses AI to suggest data quality rules for a specific field. It builds a detailed prompt from the field's profiling data and existing rules, which you send to an AI assistant. The AI responds with a list of rule suggestions that you can review and add directly to the application.

The field must have profiling data before you can generate suggestions. If the field is not yet profiled, go to Profiling in the sidebar and complete the field profiling steps first. See How to profile a field.

Step 1 — Select the field

  1. 1
    Click Rule Generator in the left sidebar.
  2. 2
    Use the four cascading dropdowns to locate the field:
    Select an Agency, then a Directorate, then a Data Set, then the Field. Each dropdown activates only after the previous one has a value.
  3. 3
    Check the summary bar that appears below the dropdowns. It shows the field name, source table, data set, profiling status, and how many rules are already allocated to this field.
    The profiling status must show Available (green) before you can proceed. If it shows Not profiled (amber), stop here and profile the field first.

Step 2 — Build and send the prompt

  1. 1
    Click Build suggestion prompt. The application assembles a prompt that includes the field's physical and semantic type, profiling results, and a list of rules already in the catalogue — so the AI avoids suggesting duplicates.
  2. 2
    The left panel shows the constructed prompt. Send it to an AI assistant using one of the buttons below the prompt:
    Open in Claude — opens Claude with the prompt pre-filled. Submit it directly.
    Open in Copilot — opens Microsoft Copilot. Use Copy prompt first, then paste it into the Copilot chat.
    Copy prompt — copies the full prompt to the clipboard so you can paste it into any AI tool.
  3. 3
    Wait for the AI to respond. It will return a JSON list of rule suggestions. Copy the entire response — including the opening [ and closing ].
  4. 4
    Paste the AI response into the AI response panel on the right side of the screen.
  5. 5
    Click Parse response. If the response is valid, a count such as 3 suggestions ready appears and Step 3 opens below.
    If a red error message appears, the AI response may have been truncated or formatted incorrectly. Try copying the response again from the AI tool and ensure you have captured the complete JSON array.
What goes into the prompt: The prompt includes the field name, database, table, physical data type, semantic type (if profiled), snapshot filter, all profiling measurements (summary statistics, type patterns, top values, length distribution, notes), and a catalogue of existing rules. The existing rules section instructs the AI not to create duplicates and to suggest reusing an existing rule where one already fits.

Changing the CDE: Selecting a different field at any point resets Steps 2 and 3. Use the Start over button in the page header to also clear the field selection and start fresh.
