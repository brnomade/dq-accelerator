How to navigate the Rules Explorer

The Rules Explorer shows the same allocation data as the Data and Stewardship page, but traversed from the rule outward. Each rule expands to show which agencies, data sets, tables, and fields it is applied to.

The hierarchy

Rules are listed alphabetically. Expanding a rule reveals the agencies whose CDEs it covers, then the data sets, tables, and finally the individual CDE (field) rows with their allocation details.

LevelWhat it shows
Rule The rule name and optional explanation. An AUTOMATED badge appears for automated rules. Summary counts show how many agencies, CDEs, and allocations this rule covers. The pencil and retire/restore buttons appear on every rule row regardless of whether it is expanded.
Agency An executive agency that has at least one CDE covered by this rule. Shows CDS, CDE, and allocation counts.
Critical Data Set A data set within the agency containing CDEs covered by this rule. Shows table, CDE, and allocation counts.
Table A source database table. Shows the table name, database, a profiled / not profiled badge, and CDE and allocation counts.
CDE An individual field. Shows the field name, profiling badge, and any criticality ratings. Click to expand and see the allocation detail: quality dimension, frequency, bumper value, and SQL viewer buttons.

Rules with no allocations

If a rule has not yet been assigned to any CDE, it shows a message instead of a hierarchy: No allocations — use the Data and Stewardship page to assign this rule to a CDE. Rules can only be assigned from the Data and Stewardship page; the Rules Explorer is a read and manage view, not the place to create new assignments.

Expanding and collapsing

Click a rule row to expand it (only possible when the rule has at least one allocation). Click again to collapse. The same applies to each nested level. All rows start collapsed.

Searching

The search box filters by rule name, rule explanation, agency acronym or name, data set name, table name, database name, and field name. The list narrows as you type. Clear the search to restore the full list.

Toolbar options

My data — visible only when your steward identity is set and you have CDS assignments. Scopes the hierarchy to show only rules that have allocations on your assigned data sets. See How to scope the view to your data sets. The preference is saved between sessions.

Show retired — appears when retired rules exist. Enables retired rules and retired allocations to appear alongside live ones. Retired rules appear faded.

The counter below the toolbar shows "Showing X of Y rules" and updates when search or filters are active. A rule counts toward the total even if all its allocations are retired, so the visible count can differ from the allocated-CDE count.
