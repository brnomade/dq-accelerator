How to view rule SQL

For each allocation in the Rules Explorer, you can view the SQL query that will be run against the target field. The application composes the SQL by substituting the CDE's source details into the rule's SQL template.

Open the SQL viewer

  1. 1
    In the Rules Explorer, expand a rule that has allocations, then navigate through the Agency, CDS, and Table levels to reach the CDE row.
  2. 2
    Click the CDE row to expand its allocation detail panel.
  3. 3
    Click one of the two SQL buttons in the allocation detail:
    The code icon opens the full composed SQL — the main aggregate check run by the rule.
    The sample icon opens the sample SQL — a row-level query used to fetch example rows that failed the check.
  4. 4
    The SQL viewer panel opens, showing the composed query, the rule name, field name, data set name, agency, and the substituted snapshot filter. Copy the SQL from the viewer to run it in Athena or another query tool.

SQL button states

What you seeWhat it means
Code icon (active) Full SQL is available and the CDE has a snapshot filter. Click to view the composed query.
Sample icon (active) Sample SQL is available (the rule has a custom sample template) and the CDE has a snapshot filter. Click to view.
DEF badge The rule has no custom sample SQL. The execution engine will use its default sampling approach. No sample SQL is viewable here.
Code or sample icon (greyed out) + warning icon The CDE is missing its snapshot filter. SQL cannot be composed until the filter is added. Edit the CDE to fix this.

How the SQL is composed

The rule SQL template contains tokens that the application replaces with the CDE's actual source details at view time. Common tokens include:

TokenReplaced with
{table}The CDE's source table name
{field}The CDE's source field name
{database}The CDE's source database name
{snapshot}The CDE's snapshot filter expression

The composed SQL shown in the viewer is exactly what would be submitted to the query engine. If the composed SQL looks wrong, check the rule's SQL template (editable via the pencil icon on the rule row) or the CDE's snapshot filter (editable from Data and Stewardship).

The SQL viewer is read-only. To change the SQL, edit the rule itself using the pencil icon on the rule row. Changes to the rule template apply immediately to all CDEs it is allocated to.
